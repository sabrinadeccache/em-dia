Premissas e escopo

Um escopo enxuto, possível de entregar no semestre

Nesta versão

  • As datas de validade são informadas pelo usuário; o sistema compara datas e não interpreta normas de cada profissão.
  • Os alertas aparecem no próprio painel, com destaque para vencimentos em até 30 dias.
  • Apenas os dados dos documentos são armazenados, sem arquivos ou imagens.
  • Cada pessoa acessa só os próprios registros, com conta pessoal.

Evoluções futuras

  • Histórico de renovações
  • Cópias digitais dos documentos
  • Avisos por e-mail e mensagem
  • Antecedência escolhida pelo usuário
  • Integração com órgãos emissores
  • Integração com a OnFreq
